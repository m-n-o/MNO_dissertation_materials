# Сопроводительные файлы диссертации "Моделирование влияния климатических и антропогенных факторов на изменение окислительно-восстановительных условий Чёрного моря"

Файл диссертации

## Состав репозитория
- Part3 - директория с материалами 3-й главы
  - brom.yaml - конфигурационный файл модели-хоста, т.е. 2DBP
  - fabm.yaml - конфигурационный файл бгх-модели, т.е. BROM
  - start.dat - рестарт-файл для 2003 года
- Part4 - директория с материалами 4-й главы
  - brom.yaml - конфигурационный файл модели-хоста, т.е. 2DBP
  - fabm.yaml - конфигурационный файл бгх-модели, т.е. BROM
  - start.dat - рестарт-файл для 2003 года
- Part5 - директория с материалами 5-й главы
  - setup.jl - конфигурационный скрипт для Варны
  - simulation.jl - скрипт запуска модели ддля Варны
